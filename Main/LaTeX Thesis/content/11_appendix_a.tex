\paragraph{Regression robustness.} The safe-haven regression of
Section~\ref{sec:results_regression} uses Newey--West (HAC) standard errors, so its inference is
robust to the autocorrelation and volatility clustering of daily returns---the main reason a
simple least-squares interaction is preferred here to a conditional-correlation model. The
crisis windows are the same event-day-to-$+20$ windows used in the event study, so the
regression and the event study rest on a common, transparent definition of each episode.
